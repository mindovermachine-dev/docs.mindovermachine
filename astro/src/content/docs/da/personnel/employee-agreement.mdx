## Stilling, tiltrædelse og arbejdstid

Medarbejderen ansættes som <span data-overload="employment.title">{frontmatter.overload.employment.title}</span> med tiltrædelse den <span data-overload="employment.startDate">{frontmatter.overload.employment.startDate}</span>.

Arbejdstiden er <span data-overload="employment.weeklyHours">{frontmatter.overload.employment.weeklyHours}</span> timer pr. uge i gennemsnit.

Arbejdsstedet er fondens adresse, med mulighed for fjernarbejde efter nærmere aftale med nærmeste leder.

## Løn, pension og sundhedsforsikring

Den årlige løn udgør ved ansættelsestidspunktet <span data-overload="compensation.salaryAnnual" data-overload-format="currency-dkk">{new Intl.NumberFormat('da-DK', { minimumFractionDigits: 2, maximumFractionDigits: 2 }).format(frontmatter.overload.compensation.salaryAnnual)}</span> kr. Lønnen udbetales månedsvis bagud og senest sidste hverdag i måneden.

Fonden indbetaler pension svarende til <span data-overload="compensation.pension.employer">{frontmatter.overload.compensation.pension.employer}</span>, og medarbejderens eget pensionsbidrag udgør <span data-overload="compensation.pension.employee">{frontmatter.overload.compensation.pension.employee}</span>.

## Ferie, fravær og barsel

Ansættelsesforholdet er omfattet af funktionærloven og ferieloven.

Ferie, sygdom, barns sygdom, barsel og øvrigt fravær håndteres efter den til enhver tid gældende lovgivning og fondens [personalepolitik](/da/personnel/personnel-policy).

## Tavshedspligt

Medarbejderen har tavshedspligt om fortrolige oplysninger, som medarbejderen bliver bekendt med i ansættelsen.

Tavshedspligten gælder også efter fratræden, dog ikke for oplysninger som lovligt er offentligt tilgængelige eller som medarbejderen er forpligtet til at videregive efter lov.

## Arbejdsresultater, open source og rettigheder

Arbejdsresultater, som medarbejderen udvikler som led i ansættelsen, herunder software, dokumentation og øvrigt materiale, tilkommer fonden i overensstemmelse med ophavsretsloven, lov om arbejdstageres opfindelser og øvrige ufravigelige regler i dansk ret.

Når fonden offentliggør materiale under en fri og åben licens, gælder licensens rettigheder for de offentliggjorte versioner og kan ikke efterfølgende tilbagekaldes for disse versioner.

Fonden kan beslutte anden licens eller lukning for fremtidige, endnu ikke offentliggjorte versioner.

Ved fratræden bevarer medarbejderen adgang til offentligt tilgængelige Open Source og CopyLeft versioner og kan anvende disse i overensstemmelse med den pågældende licens.

## Opsigelse

Opsigelse sker i overensstemmelse med funktionærlovens regler, medmindre andet skriftligt aftales inden for lovens rammer.

## Tvister

Tvister søges først løst i dialog mellem parterne. Kan tvisten ikke løses, afgøres sagen ved de almindelige domstole med Københavns Byret som værneting.
